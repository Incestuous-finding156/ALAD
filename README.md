<p>ALAD is a Chrome extension that instantly translates speech from any Chrome tab into your preferred language. Powered by Gemini 3.5 Live Translate, it supports 78 languages and works in real-time. No setup required — just install and start dubbing.</p>

<h2>🛠️ How to Use</h2>
<ol>
  <li><strong>Open Chrome</strong> and ensure ALAD is installed (look for the icon in the top-right toolbar).</li>
  <li><strong>Navigate</strong> to any tab with audio you want to dub (e.g., YouTube, Netflix, news site).</li>
  <li><strong>Click the ALAD icon</strong> to open the control panel.</li>
  <li><strong>Select your target language</strong> from the dropdown list (78 options).</li>
  <li><strong>Press "Start Dubbing"</strong> — ALAD will begin translating speech in real-time.</li>
  <li><strong>Adjust volume</strong> or pause using the on-screen controls.</li>
  <li><strong>Stop</strong> by clicking the icon again.</li>
</ol>

<h2>🐛 Troubleshooting</h2>
<ul>
  <li><strong>No sound:</strong> Check your system audio settings and ensure Chrome is not muted.</li>
  <li><strong>Extension not loading:</strong> Refresh the tab or restart Chrome.</li>
  <li><strong>Translation lag:</strong> Ensure a stable internet connection (minimum 5 Mbps recommended).</li>
  <li><strong>Icon missing:</strong> Go to Chrome extensions menu (puzzle icon) and pin ALAD.</li>
</ul>
